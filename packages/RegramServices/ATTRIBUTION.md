# Source attribution

Translation providers, LLM requests, link protection and multipart transcription are adapted from Regram iOS `f61df19a1d19e9821f7adcf5c74cbb23601d1683` under the repository license. Sources: `Regram/RGGTranslate`, `Regram/RGTranscription` and `Regram/RGSimpleSettings`. The Google HTML fallback is not included; the JSON endpoints are retained. Credentials use this Mac application’s Keychain service and account scope.

DNS transport and diagnostics follow the reference checkout’s `submodules/MtProtoKit/Sources/MTRG*` codecs, resolver and proxy policy. Font configuration, import lifecycle and pinned download catalog follow `Regram/RGSimpleSettings/Sources/FontSettings.swift` and `Regram/RGTypography`. Download catalog hashes and font OFL licenses are included as resources; font downloads remain explicit.
