Run `python3 tools/tests/regram-network-policy/run.py` from the repository root after building RegramCore Release and SwiftSignalKit for the current Mac architecture. Alternate object locations can be passed through `--core-products` and `--signal-products`.

`NetworkEditorChecks.swift` compiles the current production network controllers and TelegramCore network policy binding. The runner changes only their preference singleton reference to an isolated UserDefaults suite. It links the real RegramCore and SwiftSignalKit objects. The UI replacement keeps an old row and its action whenever its display fields are unchanged, matching InputData's action-independent equality. The checks also retain earlier actions explicitly, then change the draft before invoking them. This covers state captured before selection or typing, persistence and reload, account isolation, field propagation to the native environment, URL rejection and diagnostics cancellation. The MTContext and diagnostics request boundaries are substitutes; this portion does not connect any account.

Other form controllers can use the same fixture by adding their source to `run.py`, implementing their additional UI or service boundaries, and retaining actions before changing their draft state. Keep filesystem and account mutations in isolated test storage.

`NativeDNSChecks.m` compiles the real MtProtoKit DNS resolver, DNS codec, IP ordering and signal sources. Its URLSession configuration uses an in-process URLProtocol fixture, so HTTPS requests never leave the process. System DNS is checked only with localhost. It verifies built-in primary-provider failure and secondary-provider fallback, custom DNS success and failure, no fallback to system DNS even for a system-resolvable hostname, strict address-family queries, preferred-family fallback order, numeric-IP rejection and the custom TXT resolver used by backup discovery.

These checks do not test live Telegram TCP connections, signed backup configuration decoding, or the page's rendered pixels. They never change real network preferences or launch Regram.
