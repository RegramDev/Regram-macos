Run `python3 tools/tests/regram-settings-selection/run.py` to compile the current production navigation-selection method, the exact Regram page-to-row helper and the actual `SettingsChatController` protocol with lightweight navigation/table adapters. The harness uses no account, preferences, UI window or network connection.

The runtime checks cover Saved Messages, threads and scheduled messages; bookmark pages and descendants; returning to Pro; native business/custom-link precedence; unrelated chats; missing and reenabled bookmark rows. Source-binding guards also require the real settings table-merge callback to refresh navigation selection, both shortcuts to use independent single-item backgrounds, and the recycled bookmark action to check current preferences.

Run `python3 tools/tests/regram-settings-selection/native_shape.py` for the native selection-shape regression. It extracts the current production shortcut entries block, substitutes only the in-memory bookmark flag, and passes the resulting view types to real Release GeneralRows and TGUIKit components. An invisible host checks the native mask path at all four corners, its bounds and row CGRect, and the selected background before selection, after selecting either shortcut, and after deselection. Saved Messages is also checked with bookmarks disabled. Light and dark palettes and narrow and wide panes are covered.

The native runner links cached package objects without compiling or linking application account objects. Its separate bundle prohibits activation, and all windows remain hidden. It reads no account data or user preferences. The previous first-item/last-item production block runs as a negative control and must fail the same four-corner checks for Saved Messages and Bookmarks while retaining correct geometry and selection. Reports and build logs are saved under `/tmp/regram-settings-selection-native` by default.
