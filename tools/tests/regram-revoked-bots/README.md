# 防撤回跳过机器人消息

```sh
python3 tools/tests/regram-revoked-bots/run.py
```

在临时 SwiftPM 工程中以 Release/STABLE 加载真实 RegramCore。直接提取核心的 `rgShouldRetainRevokedMessage`，仅将共享偏好实例替换为测试专用 UserDefaults，将 Postbox 消息和事务替换为受控适配器。测试不会读取或修改已登录账号。

16 项测试覆盖默认行为、混合群里的消息作者判断、单独对话范围、防撤回关闭时不启用保留、人类向机器人发送的消息、未知或频道作者、开关恢复、账号隔离与持久化、隐私备份、设置搜索和三语文案。

同时提取生产设置页面的分组和行构建代码，以受控行模型验证主开关关闭时机器人排除项置灰且无法触发、开启后的实际保留策略、过期点击回调、子项选择记忆、独立分组及幽灵模式原有布局。另检查普通消息 ID 和全局 ID 的删除入口均传递事务与具体消息 ID，由最终应用构建验证真实核心类型与调用点。

结果和源码指纹在 `/tmp/regram-revoked-bots-20261029`。此测试不模拟服务器撤回事件、实际 Postbox 删除事务或资源清理，不代表已对真实账号执行撤回操作。
