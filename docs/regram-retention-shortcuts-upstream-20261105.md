## 防撤回与忽略计时

截图中的现象来自忽略计时入口也调用了 `rgMarkMessageRevoked`，把到期计时与服务器撤回写成相同状态。

- 忽略计时只暂停对应本机计时，不再添加撤回标记。暂停状态随原计时属性持久化，保留计时开始时间、时限与媒体保护语义，避免重新查看或重启时重新启动。自动删除与阅后即焚保持独立；云端阅后即焚媒体使用阅后即焚选项。
- 服务器撤回仍只在全局防撤回或用户明确指定的单独对话开启时保留，继续遵守机器人排除。关闭后，普通历史、搜索、媒体浏览和聊天列表不展示既有缓存中的撤回消息；保留本地记录，不重置数据库。临时显示过滤消息不会绕过防撤回开关。
- 防撤回、不保留机器人、撤回标记入口组成同一个分组。关闭主开关时，后两个入口禁用；旧回调和直接进入标记页也检查主开关。
- 标记页新增半透明开关，默认保持原有开启时的 50% 效果。关闭半透明后保留标记并恢复 100% 不透明度；普通消息与复用行均使用 100%。该选项支持设置搜索和隐私设置备份。

## 输入与关于窗口

输入框原先读取账号内的 Regram 发送偏好，原生设置页面则修改 `FastSettings.sendingType`，并且原生快捷键分发无条件将 ⌘+Enter 变成换行。

统一以原生发送选项为准，Regram 输入设置也读取和修改同一选项。普通输入、富文本草稿和媒体预览支持 Enter 发送／⌘+Enter 换行及其相反配置，包括小键盘 Enter。输入法组合期间不发送。

富文本编辑器的原始 Return 事件也经过宿主发送回调。组合输入使用独立撤销目标，在组合开始时登记原始快照，取消时只撤销该目标的登记；提交、直接调用 UndoManager 撤销、跨显式撤销分组和重做都不恢复中间候选。保留原有取消组合时不产生空撤销步骤的行为。

菜单与关于窗口使用 Regram 品牌。关于窗口的说明支持英文、简体中文与繁体中文，保留 Telegram 上游版权归属。菜单设置入口保留原来的导航行为。
