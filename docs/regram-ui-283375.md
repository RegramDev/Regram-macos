# Regram 283375：官方 UI 与底栏同步

## 上游与界面范围

同步 `upstream/master` 至 `e537320b`，合并提交为 `a23e79fc`。包含聊天搜索结果圆角与遮罩修复、群组内搜索作者消息、论坛转发菜单延迟构造；构建依赖调整及其撤回也保留在上游历史中。

聊天主界面、通用、通知、隐私及原生设置行继续使用上游组件。没有按截图另写标题栏、置顶栏或设置页。Regram Pro 内部页面沿用现有实现。

本机官方 Telegram beta 为 13.1.0（283391）。该二进制中的部分布局尚未进入当前公开源码；本轮以已公开的官方实现为准，不单独复刻尚未公开的 beta 布局。

## 原生底栏与呼叫面板

移除应用层强制文字标签、64 点高度及自定义宽度、底部搜索附件配置，回到 `TabBarController` 默认的上游悬浮底栏。旧布局偏好读取时恢复原生显示方式，保留联系人显隐。

通话标签由官方 `BaseApplicationSettings.showCallsTab` 决定。官方通用页原有“显示呼叫面板”开关保留；Regram Pro 底栏页增加同一开关，直接读写相同的 AccountManager 设置，不维护第二份生效状态。备份导出读取真实原生值，导入时恢复到官方设置。

## 横线与方形选中背景

Regram Paper 与 Graphite 的 `.palette` 曾将 `listBackground` 与 `background` 设为同色。官方 `GeneralViewType.isPlainMode` 和 `GeneralViewItemPosition.border` 根据这两个颜色是否相同选择平面列表：取消圆角，并为每一行绘制分隔线。这解释了设置侧栏方形选中背景及各设置页末行的横线。

只修正 Regram 自有主题的数据：Paper 的列表背景为 `#E8EDF2`、卡片背景为 `#F1F3F5`；Graphite 分别为 `#1E2127` 和 `#242830`。原生行组件、显式 legacy 列表与其他自定义主题没有改动。已经导入的主题需要重新导入修正版 `.palette` 才会使用更新后的颜色。
