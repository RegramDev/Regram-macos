# Regram 283376：底栏选项与设置刷新

底栏继续使用官方 TabBarController 和现有 TabBarPresentation，不另建底栏。Pro 底栏页恢复 50%–100% 宽度调节，增加“显示标签文字”。关闭文字时保留原生 48 点高度；开启后自动增加到 64 点，并同步内容底部留白。官方的居中、底部间隔、选中效果和导航目标保持原样。可点击区域约束会限制窄窗口下的最小宽度。

默认仍为原生宽度、无文字。已有宽度与文字偏好、联系人显隐和备份可以同时保留，呼叫面板继续使用官方设置。

此前任意 Pro 设置写入都会广播给聊天记录、聊天列表和设置侧栏，并递增消息展示版本，导致底栏设置也重建聊天内容、失效预览结果并重启媒体预加载。本次为设置通知加入变更键，按订阅范围发送：底栏变化只刷新导航；设置侧栏只关注自身的显示项；消息过滤只关注过滤选项。底栏变化不会递增消息展示版本。纯宽度变化不再向页面重复发送内容留白更新，只有文字开关引起高度变化时才调整留白。临时展示被过滤消息、账号重置等无键通知仍完整传播。

另一个切换闪动来自标签更新顺序：先删除末尾标签时，正在使用的设置页可能被短暂移除，再重新显示。现在先恢复当前页面对应的标签，再移除多余项，保留页面生命周期。

回归覆盖宽度、文字、联系人及备份组合，连续底栏变更的刷新计数，消息展示版本有效性，以及临时展示通知传播。原生 UI 检查覆盖明暗主题、窄宽窗口、联系人与呼叫面板显隐、文字高度/内容留白、文字与图标不重叠、调整宽度时复用控件和选中的控制器，以及聊天/设置页在联系人、呼叫面板显隐组合下不重复消失或出现。标签更新检查直接提取 MainViewController 的生产更新逻辑。
