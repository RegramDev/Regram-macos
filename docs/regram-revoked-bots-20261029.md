# 防撤回：不保留机器人消息

在“防删除与限制解除”页面中，“保留被撤回的消息”下新增“不保留机器人消息”开关，默认关闭，保持现有账号行为。

防撤回与机器人排除单独组成一个设置分组，与编辑历史、自动删除等下方开关分开。全局防撤回关闭时，机器人排除项置灰且不能操作；主开关开启后才能调整。点击回调再次读取主开关，防止旧界面回调绕过联动。关闭主开关保留子项的选择，重新开启后恢复。

开启后，全局防撤回或单独对话防撤回遇到机器人作者的撤回消息时，继续执行原有删除流程；普通作者的消息仍按原规则保留。按具体消息作者判断，群里的机器人消息和人类消息可以分别处理；人类发给机器人、由人类通过内联机器人发送或转发的消息不会仅因为涉及机器人就被排除。作者信息缺失时沿用保留规则。

该设置按账号保存，支持设置搜索、隐私设置备份以及英文、简体中文、繁体中文。没有改写自动删除和阅后即焚的独立设置，也不追溯清除此前已保留的消息。防撤回关闭或新开关关闭时，作者判断短路，不增加消息读取。

普通消息 ID 和全局 ID 两种服务器删除入口统一调用同一个判断，保留原有资源删除流程。改动限定在 Regram 偏好、设置展示、文案，以及核心防撤回桥接与两个调用点；子模块内既有其他改动保留。
