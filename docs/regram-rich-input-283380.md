# Regram 283380：移除字体自定义与富文本组合输入修复

按用户最后确认的范围，移除 Regram 的字体自定义入口及应用逻辑，集中修复富文本输入。消息预览行数保留原设置与行为；密码框检查暂停，没有修改 AuthUI、InputDataUI 或 ChatListUI。

## 字体功能

移除字体设置页、外观入口、设置搜索和深链接路由。删除应用层字体绑定，消息字体直接使用原生字体，旧字体选择不再覆盖界面或消息。已有字体文件及旧偏好保留，不删除用户数据；底层字体存储代码仍供旧账户资源清理使用。原生字号和富文本文档自身的格式保持原有行为。

## 富文本输入

原来的 macOS DocumentCanvasView 在每次 `setMarkedText` 时直接调用 `commitText`，同时始终返回没有标记文字。系统拼音的 `x → xi → xiu → xiu fu` 因而逐段追加到正文。该路径独立于普通聊天 NSTextView，上一轮普通输入框测试没有覆盖它。

现在跟踪正在组合的 UTF-16 范围，每次候选更新替换该范围，按相对选区定位候选窗口。`insertText` 尊重替换范围，确认或取消会结束组合状态。预编辑不逐次注册撤销，确认后的整段输入为一个撤销步骤；保留标题、粗体和所在表格单元格的格式。临时下划线只绘制，不写入文档属性。回车先交给输入法，组合状态下不插入新段落或触发发送。失去焦点、移动选区及结构编辑会结束当前组合。

字符坐标查询同步布局，把 `NSNotFound` 解析为当前光标并限制越界请求，返回实际覆盖范围。周边文本读取限制在连续叶区域，返回的 UTF-16 长度与 actualRange 一致，避免把跨块结构间隙当成文字。
