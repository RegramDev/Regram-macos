# Regram for macOS 13.2.0 (283467)

## 更新内容

- 修复在已归档群组发言后，旧的同步结果把群组移回主列表的问题。
- 同步 Telegram macOS 13.2 至 `ec221d85`。
- 修复聊天刷新时撤回和编辑状态被覆盖，以及资料音乐在后台刷新时恢复旧状态的问题。

## Changes

- Fix stale sync results moving a group back to the main chat list after you send a message in the archived group.
- Merge Telegram for macOS 13.2 through `ec221d85`.
- Preserve retained deletions and edit state when chats refresh, and prevent background refreshes from restoring stale profile music.

## Downloads

Requires macOS 12.0 or later. Choose the package for your Mac.

- Apple Silicon — `Regram-13.2.0-283467-arm64.dmg`
- Intel — `Regram-13.2.0-283467-x86_64.dmg`

SHA-256 digests are available in `SHA256SUMS.txt` and each package's JSON metadata.

Both packages use the existing Regram Apple Development signing identity. Follow the installation guide if Gatekeeper asks for confirmation.
