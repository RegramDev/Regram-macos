# Regram for macOS 13.1.0 (283396)

## 更新内容

- 聊天列表跳过已删除消息，回退显示上一条正常消息；防撤回保留的消息仍可在聊天内查看。
- 在“Regram Pro → 聊天与消息”新增“自己的消息靠左显示”开关，默认关闭。开启后保留发出消息的颜色和已读状态，并同步调整群聊头像、引用和侧边操作的位置。
- 修复社群添加聊天按钮被底部导航栏遮挡的问题，列表末尾预留滚动空间，并适配底栏显隐与窗口缩放。

## Changes

- Skip deleted messages in chat-list previews and fall back to the previous visible message. Retained deleted messages remain available inside chats.
- Add “Align my messages to the left” under Regram Pro chat and message settings, off by default. Outgoing colors and read receipts are preserved, with matching layouts for group avatars, replies and side actions.
- Keep the community add-chat button above the bottom navigation bar and reserve scrolling space for the last row, including bar visibility and window-size changes.

## Downloads

Requires macOS 12.0 or later. Choose the package matching your Mac:

- Apple Silicon: `Regram-13.1.0-283396-arm64.dmg`
- Intel: `Regram-13.1.0-283396-x86_64.dmg`

Each package contains executable code only for its selected architecture. SHA-256 digests are provided in `SHA256SUMS.txt` and the package JSON metadata.

Both packages use the existing Regram Apple/Mac Development signing identity and have not been notarized by Apple. Normal updates preserve existing accounts and local data. Installation details are available in the [Chinese guide](https://github.com/RegramDev/Regram-macos/blob/master/INSTALL.zh-CN.md) and [English guide](https://github.com/RegramDev/Regram-macos/blob/master/INSTALL.md).
